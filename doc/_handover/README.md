# Adoption Guide

This directory supports adoption by the AI champion and team when the operator decides the corpus is clean and advanced enough to show.

It is filled on request. Continuous enrichment can and should continue after these files exist.

## Files

| File | Purpose |
|---|---|
| [HANDOVER_SUMMARY.md](./HANDOVER_SUMMARY.md) | What was produced, what is reliable, what remains uncertain. |
| [AI_CHAMPION_GUIDE.md](./AI_CHAMPION_GUIDE.md) | Practical guide for the team AI champion. |
| [TEAM_USAGE_GUIDE.md](./TEAM_USAGE_GUIDE.md) | How the broader team should use the agents and corpus. |
| [NEXT_30_DAYS.md](./NEXT_30_DAYS.md) | Adoption plan after the operator leaves. |
| [OPEN_DECISIONS.md](./OPEN_DECISIONS.md) | Decisions the team must confirm or make. |
| [KICKSTART_CLOSEOUT_CHECKLIST.md](./KICKSTART_CLOSEOUT_CHECKLIST.md) | Exit criteria for the kickstart. |

## Principle

The adoption guide is not a presentation artifact only. It is part of the corpus lifecycle.

Adoption material should help the team know:

- what the corpus currently covers;
- what it does not cover;
- which agent to use for which type of work;
- how to capture new durable knowledge;
- how to avoid degrading the corpus through unchecked additions.
- where the roadmap says the next valuable enrichment runs are.
