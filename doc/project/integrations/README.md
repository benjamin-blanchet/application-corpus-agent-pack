# Integrations

This area contains actionable deep dives for external systems and cross-application flows.

Each significant integration should explain direction, protocol, contract, authentication, payload, error behavior, retries, observability, owners when known and change impact.

Do not rely on `INTEGRATION_MAP.md` alone when an agent needs to modify or investigate the integration.
