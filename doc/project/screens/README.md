# Screens

This area contains actionable deep dives for UI screens, views and page workflows.

Each significant screen should identify the route/view file, controller/backing bean, user roles, actions, validations, state/session behavior, downstream services, known errors, tests and impact notes.

Do not rely on feature-level prose alone when a screen has its own behavior or production issues.
