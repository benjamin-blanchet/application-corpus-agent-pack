# Update Candidates

Two uses for this file:

1. **Durable knowledge** found by non-Corpus agents before the Corpus agent reconciles it.
2. **Code-change suggestions** raised by the Corpus agent. The Corpus agent never edits application source code (see `AGENTS.md` § "Write boundaries — hard rule"). When a corpus run uncovers a needed code change, it lands here and is handed off to `developer`.
