# Demo corpus (fictional)

A **fictional** "Orders Service" corpus used only to showcase the dashboard in
the project README. It contains no real application data.

Regenerate the dashboard from it:

```bash
node scripts/build-corpus-site.mjs --doc examples/demo-corpus/doc --out examples/demo-corpus/index.html
# then open examples/demo-corpus/index.html
```

The screenshots in `docs/screenshots/` were captured from this dashboard
(Application tab → "Place in the information system" and "Features").
