# Recurring Questions

Use this file to collect questions that repeatedly appear during corpus kickstarts.

## Useful Questions

| Question | When to ask | Why it helps |
|---|---|---|
| What is the application or product name? | Start of kickstart | Prevents vague corpus naming. |
| Is this the primary application repository? | Start of kickstart | Prevents wrong scope assumptions. |
| Which Jira/project activity source is authoritative? | Before project activity discovery | Avoids invented project state. |
| Which production observability source is available? | Before production discovery | Avoids fake runtime claims. |

## Questions To Delay

| Question | Delay until | Reason |
|---|---|---|
| Detailed production hypotheses | After source registration | Premature before evidence exists. |
