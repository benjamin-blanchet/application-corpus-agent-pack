# Project activity

This area captures what connected project sources reveal about the current life of the application: active work, recurring themes, delivery flow, defects, maintenance pressure and repository activity.

It is not an individual productivity dashboard.

Use it to help the team understand trajectory, risks, active initiatives and knowledge distribution. Do not use it to rank people.

## Expected files

- `YYYY-MM-DD-project-activity-discovery.md`: initial or refreshed project activity discovery snapshot.
- `PROJECT_TRAJECTORY.md`: roadmap, migration, dependency and trajectory signals.
- `CROSS_ATLASSIAN_REFERENCES.md`: Jira/Confluence references outside the obvious project or space.
- Additional focused analyses may be added when grounded in Jira, source control, CI or team-confirmed evidence.
