# Reliability Analyses

Create one folder or file per analysis. Keep evidence, time window, sources and confidence explicit.

Use `exploration/production-temporal-correlation` for production investigations that compare several recent time slices and cross-reference signals with code, P5 catalogs and corpus bricks.

Recommended file name:

```text
YYYY-MM-DD-production-temporal-correlation.md
```
